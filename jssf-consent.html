โครงการทดสอบการใช้งาน QuickStroke สำหรับ JSSF

Community Remote Testing · Nonclinical usability and reliability pilot

หน้านี้เป็นต้นแบบสำหรับตรวจข้อความและทดสอบระบบเท่านั้น

ยังไม่เปิดรับสมัครหรือเก็บข้อมูลจากบุคคลทั่วไป แม้จะกำหนดเกณฑ์อายุและช่องทางติดต่อแล้ว แต่ยังต้องตรวจและอนุมัติข้อความขอความยินยอมฉบับจริง รวมถึงการตั้งค่าระบบก่อนเปิดใช้งาน

ข้อมูลโครงการและผู้รับผิดชอบ

สถานศึกษา: โรงเรียนสาธิตจุฬาลงกรณ์มหาวิทยาลัย ฝ่ายมัธยม

ผู้ดำเนินโครงการ: วัชรวิชย์ พงษ์ไพรัช และ สรกฤช ธัญญวรรณ์

อาจารย์ที่ปรึกษา: พริ้วฝน เทียนศรี

ติดต่อเกี่ยวกับการเข้าร่วม การถอนความยินยอม หรือการขอลบข้อมูล: kpunkfang@gmail.com หรือ kpun.wp@gmail.com

คุณสมบัติผู้เข้าร่วม

โครงการทดสอบทางไกลนี้กำหนดให้ผู้เข้าร่วมมีอายุ 18 ปีขึ้นไป และเข้าร่วมโดยสมัครใจ ผู้ที่อายุต่ำกว่า 18 ปีจะไม่อยู่ในกลุ่มรับสมัครของ JSSF remote pilot นี้

วัตถุประสงค์ของการเข้าร่วม

ศึกษาความสะดวกในการใช้งาน ความเสถียร การอนุญาตสิทธิ์อุปกรณ์ และความครบถ้วนของการทดสอบ Face, Arm และ Speech รวมถึงการลองทำซ้ำ ไม่ใช่การทดสอบความแม่นยำในการตรวจวินิจฉัยโรคในผู้ป่วย

ระบบจะส่งข้อมูลใดเมื่อเปิดใช้งานจริง

หลังจากผู้เข้าร่วมอ่านและให้ความยินยอมแล้ว ระบบจะสร้าง Study ID แบบสุ่ม และส่งผลสรุปของแต่ละรอบ เวลาที่ใช้ จำนวนครั้งที่ลองใหม่ คุณภาพการวัด รหัสข้อผิดพลาด และประเภทอุปกรณ์/เบราว์เซอร์อย่างคร่าว ๆ เข้าฐานข้อมูลโครงการโดยอัตโนมัติ

ไม่ส่ง วิดีโอ ภาพใบหน้าดิบ ไฟล์เสียงดิบ บทพูดที่บันทึก ชื่อจริง หรือข้อมูลระบุตัวตนที่ไม่จำเป็น

สถานที่จัดเก็บและระยะเวลาเก็บรักษาข้อมูล

ฐานข้อมูลหลักของโครงการใช้ Supabase และตั้งอยู่ในภูมิภาค Singapore ข้อมูลราย Session ของ JSSF ในฐานข้อมูลหลักจะเก็บเป็นเวลา 90 วัน นับจากวันที่ระบบสร้าง Session จากนั้นระบบตรวจและลบ Session ที่ครบกำหนดพร้อมข้อมูลผลทดสอบที่เชื่อมโยงโดยอัตโนมัติทุกชั่วโมง

ระหว่างการใช้งาน ระบบอาจเก็บคิวข้อมูลและสิทธิ์ที่จำเป็นสำหรับการส่งซ้ำหรือถอนข้อมูลไว้ใน IndexedDB ของเบราว์เซอร์บนอุปกรณ์ ผู้เข้าร่วมสามารถลบข้อมูลของ Session ปัจจุบันผ่านหน้าถอนความยินยอมได้ หากข้อมูลในเครื่องครบกำหนด 90 วัน ระบบจะลบเมื่อผู้ใช้กลับมาเปิดเว็บและกระบวนการดูแลความเป็นส่วนตัวทำงานอีกครั้ง

แผน Supabase ที่ใช้สำหรับโครงการนี้ไม่ได้เปิดใช้ scheduled daily database backup หรือ Point-in-Time Recovery แบบแพ็กเกจเสียเงิน อย่างไรก็ตาม ระบบผู้ให้บริการอาจยังมี infrastructure logs หรือข้อมูลเชิงเทคนิคตามนโยบายของผู้ให้บริการ การลบจากฐานข้อมูลหลักจึงไม่ควรถูกตีความว่า log เชิงเทคนิคทุกประเภทถูกลบพร้อมกันทันที

ความสมัครใจและการถอนความยินยอม

การเข้าร่วมเป็นความสมัครใจ ผู้เข้าร่วมสามารถหยุดการทดสอบได้ทุกเมื่อโดยไม่มีผลเสียต่อผู้เข้าร่วม หากต้องการถอนความยินยอมและลบข้อมูลของ Session ที่ส่งไปแล้ว สามารถใช้ปุ่ม “ถอนความยินยอมและลบข้อมูล” ในแอป หรือส่งอีเมลไปที่ kpunkfang@gmail.com หรือ kpun.wp@gmail.com หากไม่สามารถใช้ปุ่มได้

การหยุดทดสอบโดยไม่กดถอนความยินยอมอาจทำให้ข้อมูลของขั้นตอนที่ส่งสำเร็จไปแล้วถูกเก็บต่อไปจนกว่าจะครบกำหนด 90 วันหรือจนกว่าจะมีคำขอลบข้อมูล
