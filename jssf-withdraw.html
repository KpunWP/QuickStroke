QuickStroke
JSSF Remote · หน้าทดสอบระบบถอนความยินยอม

ถอนความยินยอมและลบข้อมูลการทดสอบ

เมื่อมีการเปิดโครงการจริง ผู้เข้าร่วมที่เคยให้ความยินยอมสามารถขอลบ Session นี้ได้ โดยไม่จำเป็นต้องทำการทดสอบ FAST จนครบก่อน

ระบบจะดำเนินการดังนี้

หยุดส่งผลการทดสอบเพิ่มเติม ลบข้อมูลของ Session นี้ออกจากฐานข้อมูลในเครื่อง และส่งคำขอให้ Server ลบ Session และ Events ที่เกี่ยวข้องในธุรกรรมเดียวกัน โดยไม่ลบข้อมูลการทดสอบของบุคคลอื่น

หากไม่มีอินเทอร์เน็ต

ระบบจะหยุดส่งผลการทดสอบและเก็บเฉพาะข้อมูลจำเป็นสำหรับลองส่งคำขอลบอีกครั้งเมื่อกลับมาออนไลน์ การลบบน Server ยังไม่เสร็จจนกว่าจะได้รับการยืนยัน โปรดอย่าล้างข้อมูลเว็บไซต์ระหว่างที่คำขอยังค้างอยู่

กำลังตรวจสอบสิทธิ์ถอนข้อมูลของ Session ปัจจุบัน…

หน้านี้ยังไม่เปิดรับสมัคร JSSF จริง ไม่มีการเริ่ม Session หรือส่งผลทดสอบจากหน้านี้
