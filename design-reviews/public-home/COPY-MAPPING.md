## Display rules

Fresh: home.start + index.fullName. Incomplete: index.primaryContinue + index.progress with done=1 in the synthetic fixture. Completed: home.restart + home.restartSupport, index.viewLastResult, home.moreOptions containing home.resetAction. Individual: index.individualName opens the module selector; index.fullName returns to the full view. Reset title/cancel/confirm use the proposed home.reset* roles; body remains index.newPersonBody. Disclaimer uses production disclaimer.* verbatim. All module statuses retain existing index.status* values. No extra badge, tooltip, toast or untranslated dialog text is shown.

The three language choices are TH / EN / JA, with native accessible names ภาษาไทย / English / 日本語 independent of the active locale. The group label changes with the current locale. QuickStroke stays unchanged.

## Editorial decisions still needed

All new Japanese action/helper/menu/dialog wording requires a native Japanese editor. In particular review チェック versus the existing スクリーニング terminology, the meaning of 再確認 versus starting a new round, and the tone of 最初からやり直す. No medical safety text is rewritten. Proposed English start/restart/reset distinctions and the Thai reset label need product approval.
